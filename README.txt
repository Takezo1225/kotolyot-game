КОТОЛЁТ: ЗВЁЗДНЫЙ ПУТЬ
========================

Что внутри:
- index.html — сама игра
- manifest.json — настройки установки как веб-приложения
- sw.js — кэширование для офлайн-запуска после первого посещения

Проверить на компьютере:
Откройте index.html в браузере. Для установки на iPhone сайт нужно разместить на HTTPS-хостинге
(например, GitHub Pages или Netlify). Открытие локального HTML-файла само по себе не добавит
игру на экран «Домой».

Установка на iPhone:
1. Разместите все три файла в корне HTTPS-сайта.
2. Откройте ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой».
4. Если доступен переключатель «Открывать как веб-приложение», включите его и нажмите «Добавить».

Управление:
- Перемещай кота пальцем или кнопками ← и →.
- Собирай звёзды, чтобы перейти на следующую планету.
- Избегай метеоритов.
- «РЫВОК» временно защищает от столкновений.
- С каждым уровнем препятствия ускоряются и появляются чаще.

Это прототип мини-игры. Для полноценной публикации в App Store потребуется отдельная упаковка
в нативное приложение и проверка требований Apple.
